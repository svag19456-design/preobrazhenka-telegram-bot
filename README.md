# Новости Преображенки — Telegram news intake bot

## Что умеет
- `/start`, `/news`, `/help`
- категории новости
- приём текста, фото, видео, документов
- спрашивает место/адрес (можно пропустить)
- сохраняет submissions в SQLite
- пересылает заявку в редакционный чат с кнопками одобрить/отклонить
- уведомляет автора о решении редакции

**Одобрение не публикует автоматически на сайте** — это отметка модерации; сайт пока нужно обновлять отдельно.

## Установка (Python 3.10+)
1. Создай бота через `@BotFather`, скопируй токен.
2. Укажи редакционный чат: можно личный чат с ботом, или закрытая группа, где бот добавлен.
3. Узнай числовой Telegram chat ID редакционного чата и свой Telegram user ID (числа).
4. Скопируй `.env.example` в `.env` и заполни:
   - `BOT_TOKEN` — токен бота
   - `EDITOR_CHAT_ID` — chat ID редакции
   - `EDITOR_USER_IDS` — Telegram user ID редакторов, через запятую
5. Установи зависимости: `pip install -r requirements.txt`
6. Запусти: `python bot.py`

Не пересылай токен никому и не добавляй `.env` в публичный GitHub. Если токен раскрыт — перевыпусти через BotFather.

Для круглосуточной работы нужен сервер/хостинг, который постоянно запускает Python-процесс и сохраняет файл базы данных.
